Developer journey

  1. Create a Dev Spaces workspace from this Git repository (.devfile.yaml).
  2. Run demo-up — Nexus + Lightwell proxy + JBoss (contingency or Tekton).
  3. Open app/pom.xml → Red Hat Dependency Analytics Report (CVEs / TPA).
  4. Run open-jboss-console for the management Route.
